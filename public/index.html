Page metadata as a service

Send a URL, get one JSON back: title, description, image, author, dates and keywords, normalized from meta tags, Open Graph, Twitter Cards and Linked Data.

Use it from anywhere

One GET request, no key. Responses allow cross-origin requests and are cached for a day.

curl "https://oge.fatihkalifa.com/api?url=https://fatihkalifa.com"

Where each field comes from

oge checks sources in this order and returns the first one it finds. The raw og, twitter and linkedData values come back untouched alongside.
